[네온 타이드 단독 페이지 올리는 법] — 퇴마 서바이벌(toema)과 같은 방식

처음 한 번
1) github.com → 오른쪽 위 [+] → [New repository]
   - Repository name: neontide   (이 이름이 주소가 됨)
   - Public 선택 → [Create repository]
2) 새 저장소 화면에서 [uploading an existing file] 누르기
3) 압축을 푼 neontide 폴더 '안의' 파일·폴더를 통째로 끌어다 놓기
   (index.html, sw.js, manifest.json, privacy.html, README.md, .nojekyll, icons 폴더)
   * .nojekyll 처럼 점으로 시작하는 파일이 안 보이면 없어도 동작합니다
4) 아래 [Commit changes]
5) 저장소 [Settings] → 왼쪽 [Pages] → Source: Deploy from a branch → Branch: main / (root) → [Save]
6) 1~2분 뒤 접속: https://qlddka2.github.io/neontide/

업데이트할 때
- 새 index.html과 sw.js만 [Add file] → [Upload files]로 덮어쓰기 → Commit
